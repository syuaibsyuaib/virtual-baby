Project ini merupakan eksperimen GNN pribadi yang ditujukan untuk mengeksplorasi pembentukan hubungan antar elemen kognitif dan linguistik, khususnya keterkaitan antara kata, indera, dan kondisi mental. Eksperimen ini bertujuan untuk memahami bagaimana pola koneksi semantik dan sensori dapat dibangun serta dianalisis dalam kerangka model Graph Neural Network (GNN). Selain itu, project ini juga berupaya membandingkan hasil pembentukan koneksi tersebut dengan pendekatan model GNN yang serupa untuk mengevaluasi efektivitas dan relevansi struktur relasional yang dihasilkan.
