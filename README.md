# Virtual Baby

## Overview

This project is a personal Graph Neural Network (GNN) experiment designed to investigate the formation of relationships among linguistic and cognitive-sensory elements, particularly the connections between words, sensory modalities, and mental states. The primary goal is to understand how semantic and perceptual associations can be represented and analyzed within a graph-based learning framework.

The project explores the structural interactions among language, perception, and emotional interpretation, with the aim of evaluating how graph-based representations capture conceptual relationships that resemble human understanding of meaning.

## Objective

The main objective of this project is to examine how semantic relationships are formed among:
- words,
- sensory experiences,
- and mental or emotional states.

Specifically, this research investigates whether a GNN-based model can effectively encode and infer the interconnected structure between linguistic symbols and perceptual-cognitive dimensions. In addition, the project aims to compare the generated relational patterns with similar GNN-based approaches to assess their effectiveness and interpretability.

## Methodology

The methodology adopted in this project is based on a graph representation approach, where concepts are modeled as nodes and their relations as edges. In this framework:
- words are represented as linguistic nodes,
- sensory modalities (such as sight, touch, and hearing) are modeled as perceptual components,
- mental states and emotional conditions are represented as cognitive or affective nodes.

The graph is then analyzed using a Graph Neural Network to learn latent relationships among these elements. This approach enables the system to capture the relational structure underlying language and perception, rather than treating words as isolated tokens.

## Contribution

This project contributes to the exploration of graph-based representation learning for language and cognition by proposing a structured modeling approach that connects:
- lexical information,
- sensory perception,
- and internal mental interpretation.

The contribution lies in demonstrating how GNNs can be used to model conceptual associations that are not purely syntactic or statistical, but also reflect perceptual and affective dimensions of meaning. This provides a foundation for further research on semantic understanding, context-aware learning, and multimodal interpretation.

## Experimental Setup

The experimental setup consists of constructing a graph-based dataset where each node represents a meaningful unit, and each edge denotes a conceptual or perceptual relationship. The data is organized to reflect interactions among:
- word-level elements,
- sensory-driven concepts,
- and emotional or mental associations.

The graph is then processed using a GNN architecture to learn node embeddings and relational patterns. Model performance is compared against similar graph-based approaches to evaluate the quality of learned representations, interpretability, and the extent to which the observed structure aligns with the intended semantic and sensory associations.
